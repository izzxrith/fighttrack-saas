# FightTrack

A multi-tenant platform for boxing coaches to manage fighters, log training
sessions and track fight records - each gym's data fully isolated from
every other gym's.

Built by Ayet (github.com/izzxrith) - boxer and developer.

## Status
Still in development (Started planning in August and developed it in September)

## Client
This is dedicated for my own boxing gym and also for boxing gym community out there.
